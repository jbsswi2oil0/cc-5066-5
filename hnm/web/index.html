    数学模型与正确性边界

    1. 规范切线系

    内核所有解析法线都在唯一参考系中计算：+X 朝画面右（列+），+Y 朝画面上（行−）， +Z 朝表面外，右手系。表面 H(X,Y) 的法线为

    n = normalize(−∂H/∂X, −∂H/∂Y, 1)

    编码 RGB 时才乘上所选约定的轴符号。OpenGL/Blender/Unity 预设为 (+,+,+)； DirectX/Unreal 为 (+,−,+)（绿通道朝下）。任何翻轴差异都由这组符号唯一解释。

    2. 实际尺度参与求导

    像素间距 dx=宽/列数、dy=高/行数，H=zScale·线性高度：

    ∂H/∂X = zScale·(∂h/∂col)/dx
∂H/∂Y = −zScale·(∂h/∂row)/dy

    因此只提高分辨率而覆盖同一物理表面时，差分与 dx 同步缩小，平均凹凸强度不变 （测试给出 64/128/256 分辨率下的数值）。模型拉伸倍数等价于增大 dx、dy，坡度按倍数反比变化。

    3. 传递函数不能省略

    sRGB 编码灰度 0.5 在线性光中约为 0.214。把显示编码亮度直接当线性高度会系统性夸大暗部坡度。 工具要求显式选择 linear / sRGB EOTF / γ，并在报告中保留错误示范图 srgb_ramp_naive_no_decode_opengl.png。

    4. 边界政策

    clamp（非周期）：边缘使用单侧差分，绝不从对边借像素； periodic：跨对边周期中心差分，适合可平铺纹理。边界台阶测试分别核对两种行为。

    5. 双岛镜像与标尺门禁

    两岛先按统一材料像素间距重采样，并按显式 flipCols/flipRows 定向，再拼成单一物理高度网格， 接缝是内部模板点，跨缝差分天然一致。zB 缺失时 /api/join 返回 422 scale_required：相对法线预览可用临时强度，物理合并必须先由用户补入标尺。 跨缝剖线给出左/缝/右三个坡度、残差、镜像相关与凸起/凹槽极性。

    6. 解析核对与交付物

    平面斜坡（机器精度一致）、正弦浮雕（角度误差与二阶收敛）、边界台阶、 8-bit 编解码往返误差、光照方向、分辨率不变性均有 unittest 覆盖：

    python3 -m unittest discover -s tests

    真实 PNG 贴图、光照预览与剖面图由 python3 -m hnm.cli all 生成到 assets/ 与 outputs/，汇总数值见 outputs/report.json。
